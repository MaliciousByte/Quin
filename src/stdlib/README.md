# Stdlib Module (Standard Library)

This directory contains the native API functions natively bound to the runtime.

## Core Libraries
- `array.rs`: Native operations over dynamic Arrays (push, pop, slice, sort, map, filter, etc.).
- `string.rs`: Native operations over Strings (trim, split, to_str, cases, bounds).
- `math.rs`: Mathematical and trigonometric constants / utilities (floor, power, sin, cos).
- `io.rs`: Core input/output operations (reading arrays, writing files, native parsing assertions, `print`/`emit`).
- `os.rs`: Interaction with the operating system (execution timing, exiting context, basic FS tools).
